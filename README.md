# Romania-Map-Pathfinding-Web-Application
The Romania Map Pathfinding Web Application allows users to select any start and destination cities, then compares one blind search algorithm and one custom heuristic search algorithm. The system evaluates execution time, memory usage, and path cost through an interactive and user-friendly web interface.
